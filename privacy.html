Privacy Policy

Health Dashboard is a personal application used only by its owner.

  • It requests read-only access to the owner's own data in the Google Health API (activity, sleep, and health measurements).
  • The data is stored only on the owner's own computer and is used only to display charts for the owner.
  • The data is never sold, shared with, or transferred to any third party.
  • Access can be revoked at any time at https://myaccount.google.com/permissions.

プライバシーポリシー

  • 本アプリは所有者本人のみが使用する個人用アプリです。
  • Google Health API の本人のデータ（活動・睡眠・健康測定値）を読み取り専用で取得します。
  • データは本人のコンピュータにのみ保存し、本人向けのグラフ表示にのみ使用します。
  • データを第三者に販売・提供・移転することはありません。
  • アクセス許可は https://myaccount.google.com/permissions からいつでも取り消せます。
